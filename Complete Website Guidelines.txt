Website Setup Guide

1. Open the website in VS Code
Extract hajra-portfolio-updated.zip. Open the portfolio folder in VS Code using File > Open Folder. Install Live Server, right-click index.html and select Open with Live Server.

2. Git and GitHub
Open the VS Code terminal. Run the commands in order.

git init -b main
git add index.html
git commit -m "Create home page"
git add hobbies.html
git commit -m "Add hobby lists and game tables"
git add media.html
git commit -m "Add media content"
git add contact.html
git commit -m "Create contact page"
git add css/style.css
git commit -m "Style website layout"
git add images/favicon.svg
git commit -m "Add website favicon"
git add images/workspace.svg
git commit -m "Add local image"

Make and save actual personal edits to the introduction, hobbies and contact information, then run:

git add index.html
git commit -m "Personalize introduction"
git add hobbies.html
git commit -m "Update hobby and game preferences"
git add contact.html
git commit -m "Complete contact details"
git log --oneline

3. Publish the website
Create a public repository on GitHub. Copy the remote setup commands shown by GitHub and run them in the VS Code terminal. Open Settings > Pages. Select Deploy from a branch, main, and / (root). Save.
